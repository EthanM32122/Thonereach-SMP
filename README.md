# Thonereach SMP

Welcome to Thonereach SMP!

A Minecraft 1.8.8 survival multiplayer server project inspired by Donut SMP.

## Planned Features
- Economy and player trading
- Player stats and leaderboards
- Spawn and homes
- Teleport requests
- Staff ranks and permissions
- Starter kits
- Moderation commands

## Server Compatibility
Designed for Minecraft 1.8.8 with Eaglercraft support through a compatible WebSocket proxy.

## Status
Project setup in progress.
